# Локальная проверка Ollama — 17 октября 2026

Стенд переключён с mock на установленную пользователем `gemma4:12b` через существующий `OllamaProvider`. Модель доступна на `http://127.0.0.1:11434`; `/api/tags` сообщает семейство gemma4, 11.9B, Q4_K_M, поддержку tools/thinking. Новые модели не скачивались, код агента и провайдера не менялся.

Локальный `.env` (игнорируется git): `LLM_PROVIDER=ollama`, `LLM_MODEL=gemma4:12b`, `THINKING=0`, `TIMEOUT=300`, `MAX_TOKENS_G=768`, `AGENT_MAX_STEPS=5`. Контекст 4096 и keep_alive 10 минут заданы существующим провайдером. Эти параметры API описаны в [документации Ollama](https://github.com/ollama/ollama/blob/main/docs/api.md). Локальная конфигурация и веса в git не добавлялись.

## Фактические результаты

Использовался только уже зарегистрированный синтетический `sample-data/sales.csv`; конкурсные строки в проверочные запросы не включались. Проверки выполнены отдельными локальными скриптами вне git.

| Проверка | Результат |
| --- | --- |
| `/health` | `status=ok`, `llm_provider=ollama` |
| HTTP `/agent/ask`: перечислить столбцы | 200; 2 шага; успешный `get_source_schema`; ответ содержит order_id, date, category, channel, revenue |
| Первый запрос агента после загрузки модели | 101.1 секунды; включает первое вычисление |

| Время браузерного запроса на прогретой модели | 12.9 секунды |
| Ведущие нули ID | `0001` и `0002` сохранены |
| Интерфейс | Метка «Модель: ollama», Markdown-таблица и таблица tool_results видны; pageerror отсутствуют |

Снимок браузера сохранён только в игнорируемом `frontend/test-results/ollama-live.png`. История тестового браузера не сохраняется в пользовательской вкладке.

Первый отдельный запрос к Ollama с таймаутом 180 секунд завершился ReadTimeout: по server.log запуск runner занял примерно 176 секунд. Поэтому для стенда установлен TIMEOUT=300 и перезапущен FastAPI. Указанные времена — единичные измерения на этой машине (RTX 3050 8 GiB с частичной выгрузкой слоёв в GPU), не гарантия скорости. После выгрузки модели следующий запрос снова может потребовать холодного запуска.

Стенд оставлен на `http://127.0.0.1:8000` с Ollama. Health проверяет конфигурацию приложения, а не доступность генерации модели. Большие схемы/профили, качество аналитики, длинные диалоги и SQL этим smoke-тестом не подтверждаются. SQL-исполнитель всё ещё относится к A/B. Для возврата к mock задайте `LLM_PROVIDER=mock` и перезапустите launcher.
