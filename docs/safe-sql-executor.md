# Безопасный SQL-исполнитель DuckDB

`query_data` — инструмент агента для одного выбранного CSV-источника. В SQL
источник называется `source`; физическое имя таблицы не передаётся модели.

Исполнитель принимает один `SELECT`, `WITH … SELECT` или наборную операцию над
`SELECT`. Разрешены только явно перечисленные аналитические функции. Он
отклоняет DDL/DML, несколько statements, `ATTACH`, `COPY`, `INSTALL`, `LOAD`,
table functions (`read_csv`, `parquet_scan` и т. п.), схемы/каталоги и таблицы,
не принадлежащие выбранному источнику.

Запрос запускается с read-only соединением DuckDB, выключенным внешним
доступом, лимитом памяти 128 MiB и таймаутом по умолчанию 10 секунд. До выдачи
в UI применяется лимит в 1 000 строк (не более 10 000) и 5 MiB сериализованных
данных; `truncated` сообщает о срезанном результате. Новое соединение создаётся для каждого выполнения,
поэтому отменённый тяжёлый запрос не оставляет executor заблокированным.

Ошибки SQL не раскрывают исходный текст, пути, credentials или детали DuckDB:
в инструмент возвращается только стабильный код `QUERY_REJECTED`,
`QUERY_TIMEOUT` либо `INTERNAL_ERROR`. Отдельный HTTP SQL endpoint пока не
публикуется.
