# EVIA: сверка пользовательского пути с текущим продуктом

Основа сверки — предоставленный команде `EVIA_USER_FLOW.md` от 27.10.2026. Его схемы описывают целевое поведение. Упомянутого там `docs/PRODUCT_SPEC.md` в текущем репозитории нет, поэтому статусы ниже проверены по коду и существующим API, а не по этой ссылке.

| Шаг | Сейчас | Что видит пользователь / ограничение |
| --- | --- | --- |
| Выбор данных | Есть | CSV, доступные источники и подключение PostgreSQL; состояние импорта и ошибки показываются. |
| Данные источника | Есть | Обзор, столбцы, качество, предпросмотр и схема. Объём источника и охват профиля разделены. Графики обзора считаются по предпросмотру. |
| Чат и история | Есть | Диалоги сохраняются и открываются; старые чаты без источника и чаты удалённых источников доступны для чтения. Список в боковой панели теперь один. |
| Результат ответа | Частично | Таблица, график, SQL и технические детали доступны по типу ответа; полнота и корректность AI-вычислений требуют отдельной проверки на реальных данных. |
| Сохранённый отчёт | Частично | Галерея сохранённых дашбордов открывает и пересчитывает карточки; отчёт можно явно прикрепить к вопросу. Автоматического единого отчёта для каждого анализа пока нет. |
| Печать / PDF | Частично | Открывается печать браузера, из которой можно сохранить PDF. Выбор исторической ревизии отсутствует. |
| Главная «Анализы» | Нет | Список источников и диалогов не является списком сохранённых анализов. Нет единого объекта Analysis и восстановления его контекста целиком. |
| «Добавить в отчёт», изменение блока, отмена | Нет | Нет связки результата с блоком основного отчёта и нет ревизий. Нельзя показывать эти действия как работающие. |
| Несколько источников в одном анализе и JOIN | Нет как сквозной сценарий | Источники можно добавить в каталог, но проверенный общий анализ и безопасные связи между ними не реализованы. |
| Контекст «тот же результат», «второй блок» | Не гарантирован | Нельзя обещать, что AI сохранит идентичные числа при смене представления или разрешит ссылку на конкретный блок. |

Практический следующий этап — модель Analysis/Artifact/revision и API закрепления результата. Только после этого стоит перестраивать навигацию под «Главная → Анализ → Отчёт / Данные / Чат» и добавлять кнопки редактирования отчёта. Сейчас интерфейс должен честно показывать существующие источники, диалоги, результаты и сохранённые дашборды.
