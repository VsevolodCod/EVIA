# Сохранённые результаты дашборда

При создании графика EVIA сохраняет рассчитанный результат вместе с ID снимка CSV и версией схемы источника. При открытии дашборда показывается сохранённый результат; чтение не выполняет SQL заново. Если CSV повторно импортирован или источник недоступен, ответ помечается `stale: true` и интерфейс предлагает явное обновление.

`POST /dashboards/{id}/refresh` заново вычисляет все графики. Новые результаты записываются одной транзакцией только при успехе всех графиков. Ошибка одного графика даёт HTTP 409, прежние результаты остаются доступны через `GET /dashboards/{id}/build`. Изменение порядка карточек не меняет вычисленные значения. Старые графики без сохранённого результата получают снимок при первом успешном открытии; их прежнее состояние нельзя восстановить задним числом.

Версия CSV обнаруживается по `snapshot_id` и `schema_version`. Результат одного графика ограничен 2 МиБ, чтобы крупная таблица не заполнила каталог. Для прямого PostgreSQL источник может изменить строки без изменения этих меток: автоматическое обнаружение такого изменения пока не гарантируется. Версии бизнес-метрик появятся после семантического каталога (#19). Снимки графиков не заменяют резервное копирование каталога и исходных CSV.
