# Частичное исправление #7: разделитель CSV

Исправлена причина неверных пяти столбцов при загрузке конкурсного CSV с `;`. Единый определитель диалекта используется при проверке, построении схемы, подсчёте строк, preview и profile. Поддерживаются запятая, `;`, табуляция и `|` в UTF-8/BOM. Кавычки и переносы внутри поля обрабатываются CSV-парсером. Значения preview остаются исходными строками, включая `0001`, `-123,45` и пустые значения; исходный файл не переписывается.

Уже сохранённые схемы с `parser_version<3` пересчитываются при запросе схемы. `schema_version` увеличивается один раз; повторная загрузка файла не требуется. Непустые уникальные заголовки, ширина всех строк и корректность кавычек проверяются до публикации нового источника. Повреждённый файл не регистрируется, поздняя ошибка после 500 строк также отклоняет импорт целиком.

Проверка: `python -m pytest tests/test_csv_formats.py tests/test_csv_adapter.py tests/test_api_workspace.py -q` — 22 теста. Вместе с `tests/test_contracts.py` — 45 passed. Матрица включает четыре разделителя, LF/CRLF/CR, BOM, кавычки/переносы, decimal comma, ведущие нули, повреждённые/дублирующиеся заголовки, смешанную ширину в хвосте, неизменность SHA-256 и обновление старой схемы с parser_version 1 и 2.

При дополнительном аудите найден и исправлен дефект определения разделителя для CR-only файлов: буфер пробы теперь открывается с `newline=''`, как и сам файл. Номер парсера поднят до 3. Отдельная синтетическая проверка 96 сочетаний разделителей, переводов строк, кавычек и размеров 0/1/30/3000 строк после исправления прошла полностью; до исправления не проходили 18 сочетаний с CR. Эта дополнительная проверка выполнялась локальным скриптом вне git; основные регрессии сохранены в `tests/test_csv_formats.py`.

Автоопределение остаётся эвристикой: проверяются первые 65536 символов, оценивается согласованность ширины первых записей для четырёх кандидатов, при равенстве используется `csv.Sniffer`. Если, например, и запятая, и `;` дают одинаково ровные колонки, выбор может оказаться неверным, а проверка ширины не обнаружит ошибку. Явный выбор разделителя пользователем пока отсутствует. Пробел/несколько пробелов, нестандартные и многосимвольные разделители не поддерживаются; такой файл может выглядеть как один столбец. Excel-преамбула `sep=;` не поддерживается и отклоняется как некорректный заголовок.

Это **не завершение #7**: UTF-16/Windows-1251, raw/typed SQL-представления, точная DECIMAL-типизация в Data Engine, отчёт принятых/отклонённых строк и версионирование повторных загрузок зависят от #5/#6/#7. Определение типов по 500 строкам остаётся предварительным. Все девять оригиналов здесь не проверены. Проверенный предел загрузки ещё не объявлен. Дубликаты заголовков и неправильная ширина отклоняются явно, исправление данных автоматически не выполняется.
