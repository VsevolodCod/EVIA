# Учётные записи EVIA на Railway

EVIA хранит email, имя, хеши паролей Argon2, сессии и коды восстановления в PostgreSQL. CSV, чаты и определения дашбордов продолжают храниться на томе EVIA; у каждой записи есть владелец, проверяемый сервером. Старые записи без владельца назначаются только заранее созданному владельцу `AUTH_BOOTSTRAP_EMAIL`.

## Переменные EVIA

| Переменная | Значение |
| --- | --- |
| `AUTH_ENABLED` | `1` |
| `AUTH_DATABASE_URL` | Railway reference `${{Postgres.DATABASE_URL}}` |
| `AUTH_SECRET` | Случайный секрет от 32 байт, хранить только в Railway |
| `AUTH_BOOTSTRAP_EMAIL` | Почта владельца старых источников и чатов |
| `AUTH_BOOTSTRAP_PASSWORD` | Временный длинный пароль для первого входа; после смены пароля переменную можно удалить |

При запуске с `AUTH_ENABLED=1` без PostgreSQL URL и секрета сервер не начинает обслуживать запросы. Временный пароль используется только при первом создании bootstrap-аккаунта; последующие перезапуски не сбрасывают пользовательский пароль. Не публикуйте его в Git, задачах и логах.

## Восстановление пароля

Railway блокирует исходящий SMTP на Free/Hobby, поэтому EVIA отправляет коды через Resend HTTPS API. Для включения нужны `RESEND_API_KEY` и `MAIL_FROM` с подтверждённым доменом отправителя. До настройки этих переменных кнопка восстановления недоступна. Запрос на код даёт одинаковый ответ для существующего и неизвестного email. Код действует 10 минут, допускает не больше пяти попыток, используется один раз; успешный сброс отзывает все сессии.

Если ключ Resend не настроен, владелец может войти с временным bootstrap-паролем и поменять его в мини-профиле. Обычная регистрация и вход работают без почтового сервиса.
