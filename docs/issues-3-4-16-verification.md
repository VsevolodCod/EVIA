## Работающий локальный экземпляр

Основной сервер перезапущен командой `.venv\Scripts\python scripts/run.py` с `LLM_PROVIDER=mock`. Адрес: **http://127.0.0.1:8000**, API: **http://127.0.0.1:8000/docs**. После перезапуска `/health` возвращает `status=ok`, `llm_provider=mock`; HTML имеет заголовок EVIA.

У ранее загруженного пользователем источника «01_Продажи» API подтверждает **500000 строк и 22 поля**. Предпросмотр возвращает строки шириной 22 поля; профиль — 22 колонки по выборке 500 строк. Это устраняет наблюдавшееся разбиение CSV с `;` на пять неверных колонок. Проверка не выводила содержимое строк в отчёт и не добавляла исходные данные в git. Для обновления уже открытого интерфейса достаточно перезагрузить страницу и выбрать источник.
