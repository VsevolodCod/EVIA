# Критерии и результаты EVIA

Ниже собраны сценарии и технические критерии организаторов с кратким описанием реализации EVIA и подтверждённых проверок. Вопросы для демонстрации собраны в [TestCases.md](TestCases.md); общий скринкаст будет доступен по ссылке в [README](README.md#скринкаст).

## Результаты сценариев

| № | Сценарий | Результат |
| --- | --- | --- |
| 1 | Знакомство с данными: состав, период, объём | **Проверено на сайте:** описание источника, период и число строк получены; число строк и диапазон дат совпали с источником. |
| 2 | Вопросы о содержимом, значениях и связях записей | **Частично проверено:** описание поля получено; текущий запрос на подсчёт частот по категории не выполнился. Подробности и эталонные значения — в [TestCases.md](TestCases.md#ручная-проверка-опубликованного-сайта). |
| 3 | Группировки, аномалии и повторы | EVIA предоставляет профиль источника и SQL-расчёты. Конкурсные вопросы этого сценария будут показаны в общем скринкасте. |
| 4 | Визуализация ответов | В интерфейсе доступны графики; сценарий построения по вопросу будет показан в общем скринкасте. |
| 5 | Создание дашборда по запросу | Интерфейс поддерживает сохранённые дашборды; создание и повторное открытие будут показаны в общем скринкасте. |
| 6 | Диалог с контекстом | Чаты сохраняются. Продолжения и уточнения будут показаны в одном диалоге в общем скринкасте. |
| 7 | Временные закономерности и сезонность | Вопросы сценария включены в перечень проверки; результат будет показан в общем скринкасте. |
| 8 | Сегментация и различия между группами | Вопросы нужно сопоставлять с признаками выбранного CSV; результаты будут показаны в общем скринкасте. |
| 9 | Корреляции и временные лаги | Ответ должен описывать связь по данным и не выдавать корреляцию за доказанную причину. Проверка включена в общий скринкаст. |
| 10 | Прогноз и сценарии изменения условий | Ответ и его допущения будут показаны в общем скринкасте; отсутствующие в источнике показатели не подменяются предположениями. |

## Технические критерии

| № | Критерий организаторов | Реализация EVIA |
| --- | --- | --- |
| 1 | Прямое подключение к PostgreSQL или ClickHouse | PostgreSQL подключается к заранее разрешённым таблицам с настройками администратора. ClickHouse не поддерживается. См. [руководство по PostgreSQL](docs/postgresql-source.md). |
| 2 | Загрузка исходного CSV и преобразования внутри платформы | CSV загружается в интерфейсе и профилируется при импорте. Поддерживаемые форматы и лимиты описаны в [руководстве по импорту](docs/issue-7-csv-import.md). |
| 3 | Описание структуры и содержимого и ответы на вопросы | Обзор, схема и профиль показываются в интерфейсе; ответы на естественном языке используют выбранный источник. Проверенные ответы перечислены в [TestCases.md](TestCases.md). |
| 4 | Построение и смена визуализации по запросу | Графики отображаются в результатах. Сценарии выбора представления и продолжения запроса включены в общий скринкаст. |
| 5 | Создание дашборда и повторный доступ | Поддерживаются сохранение и повторное открытие дашбордов. Сквозной пример будет показан в общем скринкасте. |
| 6 | Понятность ответов бизнес-пользователю | Результаты показываются в виде пояснения, таблицы или графика; детали расчёта доступны для проверки. Понятность оценивается на демонстрации. |
| 7 | Память на уровне диалога | История чата сохраняется и используется для продолжения вопросов. |
| 8 | Уточнение или отказ на неоднозначные и неудобные вопросы | Система может запросить уточнение или сообщить об ограничении доступных данных и операций. |
| 9 | Локальный запуск без внешних закрытых систем | Проект запускается локально в демонстрационном режиме; поддерживается конфигурация с Ollama. В README приведена [инструкция запуска](README.md#запуск-и-конфигурация). |
| 10 | Работа без облачных решений; допустимые лицензии open-source | Приложение поддерживает локальный запуск с Ollama. Опубликованная для ручной проверки версия использует Cloud.ru; соответствие этому критерию следует оценивать на локальном стенде сдачи. |
| 11 | Ограниченный доступ в интернет без поисковых движков | EVIA не выполняет веб-поиск. Ограничение исходящих соединений настраивается на стенде развёртывания. |
