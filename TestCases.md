## Ручная проверка опубликованного сайта

31 октября 2026 года проверка выполнена вручную в авторизованном интерфейсе EVIA на Railway с источником
09_Лекарственные_препараты: 876 000 строк, 6 полей, даты с 2024-10-01 по 2026-09-30. В интерфейсе был указан API
Cloud.ru.

| Вопрос                                                                                                    | Результат                                                                                                                                                                                                                                                                                                                                                |
|-----------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Что передо мной?                                                                                          | **Пройдено.** Сайт назвал источник, 876 000 строк, 6 полей и период по полю Дата. Ответ за 0,6 с.                                                                                                                                                                                                                                                        |
| За какой период эти данные и сколько в них строк?                                                         | **Пройдено.** Ответ: 876 000 строк, 2024-10-01–2026-09-30. Ответ за 6,2 с.                                                                                                                                                                                                                                                                               |
| Что означает поле «Сколько_Купили»?                                                                       | **Пройдено с оговоркой.** Дано контекстное описание числового поля и его значений. Значение нуля интерпретировано по контексту; отдельного словаря данных для подтверждения смысла не было. Ответ за 4,5 с.                                                                                                                                              |
| Какие значения поля «Тип_Лекарства» встречаются чаще всего? Назови количество строк для каждого значения. | **Не пройдено.** Сайт сообщил, что не может выполнить группировку и подсчёт. Независимая сверка исходного CSV: антигистаминное средство — 292 000 строк; жаропонижающее и обезболивающее средство, противовоспалительное и обезболивающее средство, средство для снижения кислотности желудка и средство от заложенности носа — по 146 000 строк каждое. |

Это ручная проверка нескольких вопросов на одном источнике; остальные сценарии ниже предназначены для демонстрации.
Скринкаст будет содержать общий проход по сайту и сценариям.

## Основные сценарии

| №   | Вопрос                                                         | Что показать или проверить                                                                                                                                                                                                                                |
|-----|----------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1.1 | Что передо мной?                                               | Описание выбранного источника и его содержимого. **На сайте пройдено.**                                                                                                                                                                                   |
| 1.2 | Что есть в этих данных?                                        | Поля, типы и основные характеристики. Включить в общий скринкаст.                                                                                                                                                                                         |
| 1.3 | За какой период они и сколько их?                              | Число строк и границы периода по полю даты. **На сайте пройдено.**                                                                                                                                                                                        |
| 2.1 | Что означает это поле?                                         | Объяснение выбранного поля с опорой на контекст данных. **На сайте пройдено с оговоркой.**                                                                                                                                                                |
| 2.2 | Какие значения встречаются чаще всего?                         | Значения выбранного поля и их частоты. **На сайте не пройдено** для группировки по Тип_Лекарства; эталонные частоты указаны выше.                                                                                                                         |
| 2.3 | Что связывает записи с одинаковым идентификатором колонки «Y»? | Группировка по выбранному идентификатору и объяснение связи по данным. Включить в общий скринкаст. **Пройдено с оговоркой**; ответ содержит полезные рекомендации, но избыточен и не подкреплён результатами группировки по данным.                       |
| 3.1 | Что происходит с «X» каждый июль?                              | Изменение показателя в июле по доступным годам. Подставить подходящие поля выбранного источника. **Пройдено с большой оговоркой**; с первого запроса предложил уточнение по работе. Далее показал график изменения поля по месяцам, откуда получил данные |
| 3.2 | Есть ли тут повторяющиеся данные?                              | Уточнить критерий повтора; показать найденное число и примеры, если они доступны. **Не пройдено**; предлагает уточнения по полю группировки, но это никуда не приходит                                                                                    |
| 4.1 | Покажи наглядно, как это распределено.                         | График по предыдущему результату; проверить подписи и значения. **Пройдено с оговоркой**; в контексте предыдущего вопроса строит что-то мало с ним связанное, но в общем смысле работает.                                                                 |
| 5.1 | Создай дашборд или панель с ежеквартальной статистикой с…      | Указать период и доступные показатели; проверить карточки и повторное открытие дашборда. **Пройдено с оговоркой**; создал валидный дашборд, но с одной карточкой. На запрос с уточнением со второй попытки создал еще много ежеквартальных графиков       |
| 6.1 | А теперь покажи то же самое в другом виде.                     | Задать в том же диалоге и сравнить с результатом предыдущего вопроса. **Пройдено**; уточнил, что необходимо пользователю. После уточнения создал pivot-таблицу с данными. Было вызвано после запроса 5.1                                                  |
| 6.2 | Расскажи подробнее про второй пункт.                           | Сослаться на список из предыдущего ответа; проверить ответ или уместное уточнение. **Пройдено**; корректно продолжает диалог                                                                                                                              |

## Дополнительные сценарии

| №    | Вопрос                                                            | Что показать или проверить                                                                                                                                                                                                                                   |
|------|-------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 7.1  | Какой паттерн повторяется каждые 12 месяцев?                      | Подтвердить закономерность расчётом по нескольким годам. **Пройдено**; уточнил, по какому полю искать паттерн. На последующий запрос "сам посмотри паттерны" нашел корректный ежегодный декабрьский пик по количеству продаж                                 |
| 7.2  | Есть ли сезонные пики зимой?                                      | Проверить сезонные значения и указать ограничения доступного периода. **Пройдено**; сделал то же самое, что и в предыдущем пункте                                                                                                                            |
| 8.1  | Как группируются пользователи по типу и роли?                     | Убедиться, что в источнике есть оба признака, затем показать группы и размеры. **Не тестировалось**                                                                                                                                                          |
| 8.2  | Что отличает тип X от Y?                                          | Назвать сравниваемые группы и показатели; не подменять отсутствующие поля предположениями. **Не тестировалось**                                                                                                                                              |
| 9.1  | Изменения в поле C предшествуют росту D на 5 дней?                | Проверить временной лаг; описывать связь без утверждения о доказанной причинности. **Не тестировалось**                                                                                                                                                      |
| 10.1 | Какой рост X ожидается в ближайшие кварталы при текущих условиях? | Показать метод, горизонт и допущения; при недостатке данных явно назвать ограничение. **Не пройдено с оговорками**; построил график поля X по кварталам, по нему попытался спрогнозировать будущий рост чисто по среднему изменению. Предоставил все расчеты |
| 10.2 | Как изменится Y, если изменить цену услуг типа X?                 | Проверить наличие поля цены и описать допущения; не выдавать сценарную оценку за установленную причинность. **Не пройдено** не посчитал ничего, для чего бs требовалось построение модели                                                                    |
